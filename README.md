# AI Companion Dependency Analysis

## Project Overview

This project focuses on analyzing AI companion usage and exploring the behavioral, social, lifestyle, and emotional factors associated with different levels of dependency risk.

The analysis uses a structured Python-based data analytics approach to transform raw user data into meaningful and interpretable insights. The project covers data cleaning and preprocessing, feature engineering, exploratory data analysis, correlation analysis, and data visualization. Pandas and NumPy were used for data manipulation and analytical processing, while Matplotlib and Seaborn were used to visualize trends, distributions, relationships, and patterns within the data.

The objective of this project is to examine how AI companion usage relates to areas such as social interaction, emotional attachment, lifestyle habits, well-being, and relationship patterns, and to identify notable factors associated with dependency risk.

## Objectives

- Analyze patterns in AI companion usage and user engagement.
  
- Explore relationships between AI usage and social, behavioral, and lifestyle factors.
  
- Examine emotional and well-being related patterns within the dataset.
  
- Identify relationships between key variables through correlation analysis.
  
- Analyze patterns across different dependency risk levels.
  
- Generate meaningful insights through exploratory analysis and visualization.

## Project Methodology

### Data Cleaning & Preprocessing
Reviewed and prepared the dataset to ensure consistency, quality, and suitability for analysis.

### Feature Engineering
Created relevant derived features and categories to support deeper analysis and improve the interpretation of user behavior and dependency patterns.

### Exploratory Data Analysis
Performed descriptive and exploratory analysis to understand distributions, trends, and patterns across different aspects of the dataset.

### Correlation Analysis
Examined relationships between numerical variables to identify meaningful associations and potential behavioral patterns.

### Data Visualization
Developed visualizations using Matplotlib and Seaborn to communicate analytical findings and make patterns within the data easier to interpret.

### Insight Generation
Interpreted the results to identify notable behavioral, social, and lifestyle patterns associated with AI companion usage and dependency risk.
